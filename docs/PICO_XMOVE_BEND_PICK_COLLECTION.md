# PICO XMoveBendPick 摇杆走近后弯腰抓取

独立任务 `cvpr/G1SonicXMoveBendPickPico-v0`，使用官方 `simple/G1WholebodyXMoveBendPickTeleop-v0` 的100份TRAIN初始化，每份成功录制一条。源本来就是SONIC/200Hz，保持原生地面和机器人坐标，不套用BendPick的世界平移。冻结计划从DR恢复物体初始状态，保留原始配置字节；源灯光DR为空，私有任务按已保存的layout灯具恢复，不随机生成；桌和物体材质恢复已保存值，源缺省的地面和机器人材质明确使用后端默认，不能宣称完整材质等价。

## 操作

1. 保持XRoboToolkit前台并打开Send。站直、手臂自然保持舒适姿态，松开摇杆，X校准，Y跟随。
2. 正式采集时在起点按A录制，保持姿态1秒，再松杆站稳按B进入移动。检查模式的A键不会录制。
3. 左摇杆向前、右摇杆转向。导航采用既有mode0规划控制，上身保持进入移动时姿态，手指仍由实时扳机或侧握控制。
4. 接近低桌后松杆停稳，保持进入移动时的站直身体与手臂姿态，再按B恢复全身mode2跟随。切换要求持续半秒站稳、摇杆中立、低实际速度及人体姿态匹配；拒绝切换不会结束当前录制。
5. 显示全身跟随后再屈膝、弯腰，夹住饼干盒并抬起约10厘米，稳住后A保存。摇杆在全身跟随阶段不驱动行走。
6. 每次保存或丢弃后重新站直X/Y。成功复核后进入下一初始化，失败保留同一初始化重采。

切换只改变参考控制路径与当前朝向校准，不重置机器人位置、不切断录制，不修改实际物理状态。数据记录独立控制策略 `joystick_mode0_full_body_mode2` 和编码模式 `[0,2]`。不能将其描述成导航期间持续实时全身跟随。

## 启动与验收

使用 `scripts/4090_simple/start_pico_xmove_bend_pick.sh --round-root /绝对路径/round_001 --data-root /绝对路径/data_root --collection-plan /绝对路径/manifest.json`。启动器强制 `--mobile-control-policy locked_upper_mode0`；其他策略会被新任务拒绝。`--startup-check-only`只检查真实场景与站姿；`--operator-test-only`只做实时摇杆行走和弯腰衔接检查，禁止UI及手柄录制。首次采集前需实际验证跨模式控制，静态测试不代替现场检查。

成功条件沿用本任务官方原生抓起标志（约9厘米抬升），不加人工步行距离、接触或末尾保持门槛。建议稳住约1秒便于复核。全部场景对象状态照常归档，仅目标参与原生抓取判定；不创建虚构容器。保存的原始轨迹仍需离线RTX补图、独立数据验收、打包及DINO特征处理后才能用作训练数据。
