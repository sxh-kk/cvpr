# SMPL-H K12／245维训练与验收计划

本计划保留12稀疏身体关节rotation6D＋XYZ108、显式hands21共126、参考增量9、contacts2，共245维；相机标签18、DINO5、5Hz联合重建／预测。SMPL-H完整FK及真实beta16仅用于生成K12标签和审计，没有shape预测头。只规定验证和实验，不代表已完成全量训练。当前接口见 [README.md](README.md)。

## 1. 固定数据和统计

先确认新参数归档正式accepted且独立验收不再pending，再复用其meta/splits.json：EgoSuite人物／录制与HM participant／capture分组。记录实际规模，确认分组无交叉。冻结manifest与归档fingerprint、SMPL-H模型SHA、表示版本、代码版本、随机种子、窗口11/prefix6/stride5、源抽帧步长6、joint监督与接触阈值。

两来源使用同一个真实16维shape SMPL-H模型计算完整body22 FK，再选择既有K12索引 `[0,4,5,10,11,13,14,15,18,19,20,21]`。监督这些关节的模型定义轴，不使用旧EgoSuite原生轴映射。保留源观察／模型完成／confidence与原始认证标记，分别报告两来源质量和手点覆盖。HM发布优化参数不是独立捕获真值；模型定义轴不认证EgoSuite绝对旋转精度。

统计使用全部train有效窗口，累计245/18逐维count、mean和std；只读DINO有效性，不加载embedding、不读val/test。K12身体和双手依据各自mask，HM逐帧shape在FK中保留但不统计为运动通道。fore地面兜底仅用前6帧原来源脚点。累计全11帧有效标签，缺失／常量维单位尺度，contacts不归一化，重复增量共享统计。即使同为245维，旧原生轴统计也不可复用；诊断或限量统计不可用于正式训练。

正式视觉训练要求 DINO5 已实际提取，不能只有 schema 已升级。默认历史6帧有效视觉帧比例至少0.5。报告按来源的接受/拒绝窗口数、原因、手/身体位置/旋转/接触标签覆盖率、DINO覆盖率和地面兜底比例。运动统计与视觉训练采用同一历史图像有效性过滤，并且仅使用train分组。

## 2. 几何和接口门槛

自动回归与真实只读抽样须先通过：

- 非零世界原点、yaw、负/零地面高度下，encode→decode 恢复身体XYZ、关节旋转矩阵、双手点和相机地面轨迹；浮点误差应在1e-5m/1e-5矩阵元素量级内。
- 固定每6个30Hz源帧取一帧得到5Hz，增量跨6个源帧，接触阈值使用物理速度；不跨时间戳缺口。
- body旋转/XYZ与逐点手 mask 独立；统计排除失效标签，padding不参与损失。
- 预测只使用前缀条件。改变未来轨迹、图像、图像有效标记或隐藏值NaN，不改变同seed预测；仅前缀输入与完整窗口屏蔽输入一致。
- 标签有效性影响评价覆盖率与训练损失，不限制未来采样状态；旧153维checkpoint/mask和不匹配的统计不能加载。
- 默认显式fore禁用原随机整段／首帧图像dropout；训练逐样本以0.5概率开放历史6帧有效轨迹，其余隐藏，未来轨迹始终隐藏。验证／推理忽略训练开放概率，始终仅用历史图像。历史与未来均参与损失和采样更新；真实缺失依独立mask处理。actual400M前向/反向、训练入口Adam＋EMA均成功，历史图像可影响未来预测。

地面兜底额外测试未来脚点扰动：fore观测条件和兜底地面不能改变。归档离线估计的地面可能使用全序列信息，因此严格在线结果必须另列已知地面/前缀可估地面两种假设；没有输入脚点的纯视频部署不能使用真实脚点兜底。

## 3. 小规模训练验收

先在固定少量 train 录制上运行短训练，完整 val 分组隔离。检查6D、XYZ、左右手、全局旋转/平移、contacts的有效计数和损失是否下降，以及新输入/输出/视觉投影、历史／未来运动梯度、MoE路由概率、负载和aux loss。有有效历史轨迹的开放样本应使轨迹投影获得有限非零梯度；纯图像样本仍应正常训练。fresh训练全参数从epoch0学习。

固定数据、步数、seed、优化器和其余超参数，对比 `TRAJECTORY_CONDITION_PROB=0 / 0.25 / 0.5`。0.5为缺失模态训练的起始实验值，不是UniEgoMotion原始整段／子序列mask概率的复刻，也没有已验证的最优结论。只按纯图像val未来5帧身体／手／旋转／轨迹指标选概率，并按来源分组；不要依据混合train总loss判断部署收益。仅改变此概率无需重算同表示统计，但checkpoint protocol不同，各对照应分别fresh训练。

默认保留有效通道MSE与global_weight=8，做 **1/2/4/8** 权重对照，固定其余条件。245维全有效时，加权通道合计308，全局约23.4%、双手40.9%、身体旋转23.4%、身体XYZ11.7%、contacts0.6%；真实比例随mask变化。报告各组有效计数，并按held-out姿态和轨迹选择权重，不能只看总loss。没有beta损失或beta预测误差指标。

本阶段不默认加SO(3)角度loss、接触分类loss、FK或SMPL约束；角度/物理指标用于判断是否需要后续独立消融。

## 4. 实际采样验证

每5个epoch对固定val子集进行纯历史图像fore的10步Euler采样，主指标只评价未来5帧（1秒）。历史6帧是联合重建监督目标，可另报辅助重建误差。每个指标报告单位和有效count，world指标报告可积分reference chain覆盖率与失败比例。完整评估再扩展到全部val录制，避免短窗口子集代表全体的假设。

| 任务 | 可见条件 | 主评估区域 |
|---|---|---|
| 默认joint fore训练 | 历史6帧DINO；逐样本0.5概率开放历史6帧轨迹，未来条件隐藏 | 训练监督完整11帧 |
| 默认joint fore验证／部署 | 仅历史1秒＋当前的6帧DINO，无真实相机轨迹 | 未来1秒的5帧 |
| 旧15Hz实验 | 沿用各自checkpoint的recon/fore/gen条件 | 沿用对应时间协议，不与新5Hz资产混用 |

至少记录：

- 身体local/world MPJPE，左右手local/world MPJPE（米），身体rotation角度（度）和退化6D比例。
- floor每步平移/旋转误差、累积ATE、末帧漂移和yaw误差；世界身体/手坐标必须使用**预测增量**恢复。
- 接触accuracy/F1和预测接触率，脚穿地深度（米）、预测接触时脚速度（米/秒），双手wrist与身体wrist一致性。不能只看脚滑动而忽视模型全部输出“无接触”的情况。
- 根据来源、手部完整/部分缺失、地面兜底与否、活动种类分组，报告覆盖率；某组无标签应记为不可评估，不能记0误差。

fore世界还原只以最后观测参考位姿为锚点。参考真值链缺失时停止该连续段的世界评价并报告覆盖率，不能在未来用真实相机重新锚定预测，也不能把无效delta当单位运动。

gen/fore具有多解性，完整验收对每窗口使用至少5个固定seed，分别报告单样本均值、样本间标准差和best-of-5；best-of-5单独标注，不能作为单次部署性能。对原始录制分组进行bootstrap给出置信区间，不能把重叠窗口当独立样本。周期快速验证默认只采一次，CLI可更换seed输出多个JSON供汇总。

## 5. 全量训练与部署

小规模结果无异常、视觉数据与完整train统计就绪后开始全量训练。只用val选checkpoint/权重和超参数，最终固定配置后一次性验收test。需要报告train/val/test实际规模、checkpoint epoch/step、EMA或普通权重、归一化和关节轴来源。

除运动采样，还验证t=1一次调用的 `[B,T,768]` hidden和 `[B,768]` global：同seed复现、无未来泄漏、有效帧标记正确、下游训练头可获得梯度、实际GPU设备的延迟/显存和5Hz历史抽帧一致性。结构成功不等于特征已经对动作任务有效，仍需下游固定任务对照。
